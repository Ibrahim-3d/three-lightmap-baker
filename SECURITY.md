# Security Policy

## Supported versions

The current `1.x` stable line is the supported public package line. Changes on
`master` are unreleased development until they appear in a tagged GitHub/npm
release.

Security fixes may require users to update to the latest supported release.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a suspected vulnerability.

Preferred reporting path:

1. If the repository Security tab offers **Report a vulnerability**, use GitHub's
   private vulnerability-reporting flow.
2. If private reporting is not available, contact the maintainer through the
   GitHub profile before public disclosure and provide enough information to
   establish a private channel.

Include, when applicable:

- affected package version or commit;
- impact and attack scenario;
- reproduction steps or proof of concept;
- browser/runtime context;
- any known mitigation.

Public disclosure should wait until the issue can be assessed and a fix or
mitigation can be coordinated.
